How It Works

This dashboard utilizes a multi-model Soft-Voting Ensemble Engine to predict machine component failures before they occur.

  • Random Forest: Analyzes non-linear sensor relationships and reduces prediction variance.
  • LightGBM: Handles fast leaf-wise gradient boosting across continuous telemetry streams.
  • XGBoost: Optimizes regularization to prevent false alarms on rare failure modes.
Probability outputs are averaged across all three models to ensure maximum diagnostic reliability.
